# Aspirantes CIMAT

Aplicación Laravel para el registro, evaluación y consulta de aspirantes de un
proceso de selección.

## Documentación

Las instrucciones de instalación, ejecución con Docker y las decisiones
técnicas se encuentran en el [README principal](../README.md) y en
[docs/DECISIONES.md](../docs/DECISIONES.md).

## Inicio rápido

```bash
cp .env.example .env
docker compose up -d --build
```

La aplicación queda disponible en <http://localhost:8080>.
